The funniest single line of wedding vows a robot couple could say, written for the [make.fun](https://make.fun) bounty **One-Line Robot Wedding Vows**.

## Entry

> I take you to be my lawfully wedded unit, to have and to hold, in sickness and in health, until a firmware update do us part.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic, Python stdlib only.
